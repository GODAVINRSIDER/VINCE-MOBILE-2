WHAT THIS ACTUALLY IS
--------------------------
Not another chat AI provider - a SEARCH tool. This is the real fix for
what you were asking about: date/time awareness (already fixed) tells
VINCE when it is; this tells it what's actually happening, by fetching
real current web results when a question needs them and handing them to
the AI before it answers. Same pattern that lets me answer current-
events questions - retrieval, not extra training.

Uses Tavily - a search API built specifically for AI agents (returns
clean text, not raw web pages to parse). Free tier: 1,000 searches a
month, no card needed to sign up at tavily.com.

HOW IT DECIDES WHEN TO SEARCH
----------------------------------
Not every message - that would slow down ordinary chat and burn your
free searches for no reason. It only reaches for the web when your
message sounds like it needs current info: words like "latest,"
"current," "recent," "this week," "today's," "search for," "news
about," "who is the current," etc. Ordinary conversation and anything
that doesn't need live info skips it entirely and answers normally,
same speed as before.
