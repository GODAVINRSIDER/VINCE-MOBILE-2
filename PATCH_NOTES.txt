MALE VOICE LOCKED IN + DELETE CHATS + FULL BACKUP/RESTORE + CLEANUP
========================================================================

EXTRACTION - same as always: extract straight into your project folder,
choose overwrite. Confirm app/src/main/java/com/godavin/vince/
BackupManager.kt exists afterward (new file).

1. VINCE VOICE - LOCKED IN, SETTING REMOVED
   "en-us-x-iom-local" is now hardcoded as VINCE's voice. The dropdown
   and the whole "VINCE voice" section are gone from Settings - nothing
   left to configure, it just works now. (If that exact voice somehow
   isn't installed on this device, it quietly falls back to the same
   lower-pitch trick as before rather than breaking.)

2. DELETE CHAT THREADS
   Chats list - each thread now has a "Delete" link. Tapping it asks for
   confirmation first (shows the thread's title, warns it can't be
   undone) before actually removing anything.

3. FULL BACKUP & RESTORE (Settings > "Backup & restore")
   - "Export & share backup" bundles EVERY chat thread, EVERY structured
     memory fact, and the activity log into one file, then opens
     Android's normal share sheet - send it to your own email, Drive,
     WhatsApp, wherever you want to keep it safe.
   - "Restore from backup file" picks that file back up (via the system
     file picker) and restores everything from it - meant for a fresh
     install on a new phone, or after reinstalling, so you're not
     starting over.
   Why this shape instead of literally "install an email account": a
   real automatic email integration needs Gmail's OAuth API or a mail
   server - ongoing infrastructure, API keys, consent screens, ongoing
   maintenance. This solves the actual problem (don't lose everything
   on a phone switch) using Android's own share sheet - works with
   whatever mail app you already have, no new account or cost involved.

4. CONVERSATION MEMORY WINDOW INCREASED (20 -> 60 messages)
   Important distinction: your FULL chat history was already being
   stored forever on-device (nothing was ever silently deleted) - the
   "20 messages" limit only controlled how much of that history got fed
   into each individual AI reply, to keep replies fast/affordable. That
   cap is now 60 - a real, meaningful bump. Going fully unbounded isn't
   actually free to do: every message in that window rides along on
   EVERY single reply, so no cap at all means every message in a
   long-running thread gets slower and more expensive to answer over
   time, and would eventually hit the AI model's own hard context
   limit. 60 is the practical sweet spot. The backup/restore feature
   above is the real fix for "never lose anything, even switching
   phones" - that keeps everything, forever, uncapped.

5. LIVE PRICES + REMINDERS - REMOVED FROM COMMAND HANDLING
   Per your call to drop both: "remind me..." and price questions
   ("what's the price of...") no longer get intercepted locally at all -
   they fall straight through to the AI persona now, which will just
   answer conversationally (e.g. explain it can't check live prices)
   instead of hitting a broken local fetch or a reminder that wouldn't
   fire reliably. Time, date, and the economic calendar are unaffected -
   those always worked fine.
