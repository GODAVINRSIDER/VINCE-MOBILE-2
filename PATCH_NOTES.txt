DISCARD DEEPSEEK + CONCISE RESPONSES + VOICE FIXES
========================================================

EXTRACTION - same as always: extract straight into your project folder,
choose overwrite.

1. DEEPSEEK - FULLY REMOVED
   Pulled back out per your call - Settings field, API key slot, and the
   BrainRouter fallback branch are all gone. Back to Gemini -> Groq ->
   OpenRouter, same as before any of this started.

2. RESPONSES - CONCISE BY DEFAULT, NO MARKDOWN
   Every persona now gets a standing instruction: keep replies short and
   to the point by default (key takeaway in a few sentences), then ASK
   if you want the fuller detail rather than dumping everything at
   once - your call whether to go deeper. Also told to never use
   Markdown syntax (no ##, **, tables with | or ---, bullet dashes) -
   this chat has no Markdown renderer, so those were just showing up as
   literal symbols cluttering the bubble, exactly like your screenshot.
   Applies to chat AND chart/photo/screen analysis - that prompt got the
   same treatment (quick one-line read, then asks if you want the full
   breakdown instead of front-loading a table every time).

3. TIMEFRAME PRONUNCIATION FIXED (VOICE ONLY)
   "15m" was being read as "15 metres." Now speech-cleans trading
   shorthand before speaking: 15m -> "15 minute", 1h -> "1 hour", 1d ->
   "1 day", 1w -> "1 week". On-screen text is untouched - this only
   changes what gets spoken.

4. TABLE DASHES NO LONGER READ ALOUD
   Whole lines that are just a Markdown table separator (a row of
   dashes/pipes) or a "---" divider now get dropped entirely before
   speaking, instead of VINCE reading out a string of "dash dash dash."
   Combined with fix #2 above (AI told not to produce tables in the
   first place), this should rarely even come up going forward, but
   it's a safety net either way.

5. IN-CHAT MIC - SAME FIX AS THE WIDGET/HOME MIC
   Found it: the mic button INSIDE a chat was still launching Google's
   own floating "Speak now" popup, even after the widget and Home mic
   were already fixed to skip that. Now uses the same direct-speech
   approach - no popup, just the mic button's own border/background
   lighting up and saying "Listening..." while it's picking up your
   voice.
