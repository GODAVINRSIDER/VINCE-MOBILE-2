VINCE MOBILE 2.6.1 (versionCode 8 / versionName 2.6.1-phone)  -  includes 2.5 and 2.6
==========================================================================================
Extract into your project folder and overwrite (zip root is app/ - no wrapper folder).
app/debug.keystore is untouched - do not replace it.

FIXES IN 2.6.1
A. ONE BAD VOICE NO LONGER KILLS THE REST. A rejected voice ID (wrong ID, or a library voice
   your plan can't use through the API) used to switch ElevenLabs off for ALL voices for 30
   minutes - that was the "Vince on and off". Now only that voice falls back; a wrong key or an
   empty quota still affects all of them.
B. THE REAL REASON IS SHOWN. Settings > Voice now prints the last ElevenLabs error
   (e.g. "CLARA: HTTP 402 paid_plan_required"). Save voice settings clears old problems.
C. NO MORE PAUSE AFTER EVERY FULL STOP ON THE PHONE VOICE. 2.5/2.6 spoke the phone voice one
   sentence at a time, and Android leaves a gap between queued sentences. The phone voice now
   speaks the whole reply as one utterance again (like 2.4). Sentence-by-sentence is only used
   for ElevenLabs. If ElevenLabs fails mid-reply, the rest is handed to the phone voice as ONE
   piece, not sentence by sentence.

NEW IN 2.6
1. GUIDED PHONE-CONTROL SETUP (Settings > Phone control). One button walks you through
   restricted settings -> Accessibility -> Notification access, opens each screen, shows the
   exact taps, ticks each step and opens the next one by itself when you come back. No adb,
   no laptop, works on any phone.
2. BACKUP RESTORE FIXED. Cause: the app kept its old chats in memory and wrote them back over
   the restored file on the next message. Also the file picker greyed out .json files that
   Drive/WhatsApp label as another type. Now: cache is dropped after restore, the file is
   checked before anything is overwritten, current data is kept as *.before-restore, any file
   type can be picked, and the result says what came back ("12 chats (340 messages)").
   (Chat photos are not part of the backup file - only chats, memory, activity.)
3. ELEVENLABS VOICE (Settings > Voice). Main voice for VINCE/CLARA/DAVINA when a key is saved;
   the phone's own voice is the automatic fallback (no key, switched off, offline, quota used
   up). Speaks sentence by sentence while the rest downloads, so first words come fast.
   Enter your voice IDs per persona (defaults are stock ElevenLabs voices).
4. NO MORE LONG PAUSES AFTER A FULL STOP. Paragraph breaks used to be turned into ". " right
   after an existing full stop (".. "), which the phone voice rested on; ellipses did the same.
   Now they become short comma pauses. (ElevenLabs has no such pause at all.)
5. LIVE STATUS NARRATION. While VINCE works it shows, and says out loud in the active persona,
   what it is doing: "Give me a moment, searching the web for X" / "Found it. Reading
   reuters.com and fxstreet.com" / "Checking where you are" / "That brain is slow, switching".
   Spoken only if you are still waiting after ~1 second, max 3 lines per reply.
6. HISTORY CAP 40 messages (was 24 in 2.5, 60 before).
7. LOCATION (Settings > Location & places). Real-time location for "where am I", "near me"
   (adds your area to the web search), distances and "navigate to X" (opens Google Maps).
   Optional place memory: remembers where you've been for 48 hours or 7 days (your choice),
   erases anything older automatically, stored only on the phone, never in backups.
   "Clear history now" button. For all-day memory choose "Allow all the time".
