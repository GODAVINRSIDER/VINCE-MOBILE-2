DashboardScreen.kt exists afterward (new file).

1. VOICE DROPDOWN STYLING - FIXED
   Was using Compose's plain filled TextField (solid grey box, looked
   broken). Switched to OutlinedTextField, matching the API key fields
   above it in Settings.

2. DASHBOARD VISUAL PASS (the locked "ONE CORE, THREE MINDS" layout)
   The Home screen is now the real dashboard from the reference image,
   not the old plain button list. Built to the same discipline as
   everything else in this project: every number/status you see is a
   real read, nothing fabricated to look good.

   - System overview panel: real CPU load (best-effort - some phones
     block this at the OS level, shows "N/A" there rather than a fake
     number), real RAM used %, real battery % (+ charging indicator),
     real active network (Wi-Fi/Mobile data/Offline). Refreshes every
     3 seconds automatically.
   - Wedge ring: a circle split into VINCE/CLARA/DAVINA thirds, the
     active persona's third lit up bright, the other two dimmed, with
     the VINCE triangle logo centered. Tap any third to switch persona -
     same shared state as switching inside a chat or on the floating
     widget.
   - Active persona card: shows the real most recent thing that persona
     actually said across all your chats (or "Ready" if nothing yet).
   - Activity panel: your real recent actions - sending a message,
     analyzing a photo/screen, opening another app - each with a real
     relative time ("3m ago"). "See All" opens the full log.
   - Memory panel: your real structured-fact count, real chat thread
     count, real total message count. "See All" opens the actual list
     of facts VINCE has saved about you (not sample data).
   - Quick actions: New chat, All chats, Settings, and the floating
     widget toggle (moved here from the old Home screen).
   - Bottom row: Chat tile, a working mic button (same voice pipeline as
     everywhere else - speaks the answer AND shows it as a toast since
     there's no chat bubble on this screen), and a Status tile showing
     real online/offline state.

   Reminders/PC Control from the original reference image were left out
   - reminders are parked per your call, and there's no PC in this
     build at all (by design, since Stage 1). Everything shown instead
     is a real capability this app actually has.
