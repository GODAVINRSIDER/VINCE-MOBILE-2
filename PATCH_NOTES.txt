1. VISION FALLBACK - ACTUALLY FIXED THIS TIME
   Your screenshot showed both fallback models returning 404 "model not
   found" - I'd guessed two model names that turned out not to actually
   exist/be accessible. Real fix:
   - Groq: switched from the preview-only model that failed to
     "meta-llama/llama-4-scout-17b-16e-instruct" - Groq's standard,
     broadly-available vision model.
   - OpenRouter: instead of guessing another hardcoded free-model name
     (proven fragile - that's exactly what broke last time), it now
     asks OpenRouter's own live model list which vision model is
     currently free and uses that automatically. This is the real,
     durable fix - if OpenRouter's free vision model changes again in
     the future, this adapts on its own instead of breaking again.

2. PIN SECURITY - CLOSED THE HOLE YOU FLAGGED
   Removing the PIN now requires typing the current PIN first - no more
   one-tap disable on an already-unlocked phone. Also added a recovery
   option: set a security question (Settings, alongside the PIN) so a
   forgotten PIN isn't a permanent lockout - the lock screen gets a
   "Forgot PIN?" link that, once you answer correctly, lets you set a
   brand new PIN right there.

3. CHAT - JUMP TO LATEST + EXPANDING INPUT BOX
   - A small down-arrow button now appears once you've scrolled away
     from the latest message - tap it to jump straight back down instead
     of scrolling by hand.
   - The message box now grows as you type a longer message (wraps and
     expands, up to about 6 lines) instead of staying one thin line with
     earlier text sliding out of view.

4. WIDGET SURVIVES A REBOOT NOW
   If the floating widget was on, it automatically comes back after your
   phone restarts, instead of staying off until you manually reopen the
   app and flip it back on.

5. RETRY ON FLAKY NETWORK HICCUPS
   A genuinely transient failure (dropped connection, timeout) now gets
   retried once before giving up on that provider - a half-second
   network hiccup shouldn't cost a whole provider attempt the way a real
   quota/auth error should.

6. RING - PUSHED FURTHER (same honest caveat as before: still not
   literal 3D, that needs a different kind of tool entirely)
   Added an off-center highlight on the hub and each persona circle
   (simulates a light source, a real bevel/sphere cue flat gradients
   can't give) and a thin bright rim border around each - genuinely more
   dimensional than before. Judge for yourself if it's closer to what
   you wanted.
