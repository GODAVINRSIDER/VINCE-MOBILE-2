WHAT'S NEW - SECURITY/PIN LAYER (merged in, per your ask to move fast)
--------------------------------------------------------------------------
Settings now has an "App lock (PIN)" section at the bottom:
- No PIN set = app opens straight in, exactly like before - nothing
  changes unless you set one.
- Set a 4-8 digit PIN and it's required once per FRESH app launch
  (force-close, reboot, task-killed) - not on every screen, not every
  time you background/foreground the app while it's still running.
- Stored as a one-way hash only, never the plaintext PIN.
- Remove it any time from the same Settings section.

Worth having now specifically because VINCE can open other apps,
run a floating widget, and read your screen - more reason to lock it
down than when it was just read/answer chat.
