WHAT'S NEW IN THIS ROUND (on top of last patch)
-------------------------------------------------

1. VINCE MALE VOICE - changed approach
   The old "search voice names for the word 'male'" trick doesn't work -
   most engines, including the one built into basically every Android
   phone, don't label voices that way at all (names look like
   "en-us-x-iom-local", no gender word in them). So it was always
   silently falling back to the lower-pitch version.

   New approach: Settings now has a "VINCE voice" section listing every
   voice this phone's engine actually has installed. Tap any voice name
   to hear it, tap "Use" on the one that sounds right, done - it's saved
   and VINCE uses it from then on. This is a one-time ~30 second setup
   per device and is guaranteed to work, unlike guessing.
   (A single WAV file can't work here - a WAV is one fixed recording,
   but VINCE needs to speak whatever text comes up in conversation. That
   needs an actual text-to-speech voice, not a sound clip. If none of the
   installed voices sound right, the next step up is a paid cloud voice
   API like ElevenLabs or Google Cloud TTS, which is a bigger, separate
   feature - happy to build that if the on-device options aren't good
   enough on your phone.)

2. REMINDERS NOT FIRING IN BACKGROUND - real cause found
   Reminders were only firing while the app was open. Cause: your phone's
   Android skin (very common on Tecno/Infinix/Itel/Xiaomi-family phones)
   aggressively kills background apps unless the app is explicitly
   exempted from battery optimization - which silently stops the
   reminder's alarm from ever reaching the app, even though the alarm
   itself was correctly scheduled.
   Fix: the app now asks, once on launch, to be exempted from battery
   optimization (a system permission popup will appear - allow it).
   NOTE: some phone brands also have a separate "Autostart" or
   "Background app management" toggle in their own settings app (outside
   Android's own settings) that Android has no API to control - if
   reminders still don't fire in the background after allowing battery
   optimization, check your phone's own Settings > Apps > VINCE for an
   "Autostart" / "Allow background activity" toggle and enable it there
   too. Tell me your phone brand/model if unsure and I'll get you exact
   steps.

3. APP TITLE - changed "VINCE 2.0" to "GODAVINRSIDER" on the home screen.

4. PERSONA NAME BESIDE CHAT LIST ENTRIES - each thread in the Chats list
   now shows which persona last replied in it, beside the title.
