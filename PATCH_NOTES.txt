VISION FALLBACK CHAIN - PHOTO/SCREEN ANALYSIS NO LONGER DIES WHEN GEMINI QUOTA HITS
========================================================================================

EXTRACTION - same as always: extract straight into your project folder,
choose overwrite. Confirm app/src/main/java/com/godavin/vince/
VisionRouter.kt exists afterward (new file).

WHAT CHANGED
---------------
Photo and screen analysis now falls back automatically, same as chat
already does:
1. Gemini's vision API (unchanged, still tried first - best quality)
2. If that fails (quota, timeout, anything) -> Groq's vision model
3. If that also fails -> OpenRouter's free vision model

This applies everywhere vision is used: in-chat Camera/Screen buttons,
the floating widget's two-finger camera/screen gestures - all three now
go through the same fallback chain.

No new key needed - this uses the SAME Gemini/Groq/OpenRouter keys
already in Settings for text chat. If you only have a Gemini key saved,
behavior is unchanged (no fallback available, same as before). Add a
Groq and/or OpenRouter key if you haven't already, to actually get the
benefit of this.

ONE THING TO KNOW
---------------------
Groq and OpenRouter's vision models are solid but not identical in
quality/style to Gemini's - if a photo analysis ever reads a little
different in phrasing when you've hit Gemini's quota, that's why: it's
a different model answering, not a bug. The underlying chart-reading
prompt/instructions are identical either way.

TESTING CHECKLIST
--------------------
1. Confirm VisionRouter.kt exists after extraction.
2. With your Gemini key still working, do a normal chart photo analysis
   - confirm it works exactly as before (Gemini, unchanged).
3. To actually test the fallback: temporarily clear/break your Gemini
   key in Settings (or wait until you hit quota again), then try a photo
   analysis - confirm it still gets a real answer instead of failing,
   coming from Groq or OpenRouter this time.
4. Put your real Gemini key back afterward if you cleared it for testing.
